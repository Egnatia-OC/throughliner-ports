Notes & caveats

  • FlutterFlow learning curve — reclassified as a "developer tool" in the February 2026 independent State of App Building report. Reddit community estimates 200+ hours. Requires external database setup (Firebase/Supabase) on top of the platform itself.
  • FlutterFlow code export — requires paid plan (~$39/mo Basic or higher). On the free plan you build but cannot export, which means lock-in until you upgrade.
  • Webflow CMS lock-in — static HTML/CSS exports cleanly, but CMS content, forms, ecommerce, and site search are tied to Webflow's servers and require third-party replacements if self-hosting.
  • Glide / Softr data portability — data lives in an external source (Google Sheets, Airtable). The data is portable; the app built on top of it is not. These are two different things.
  • SAP Build Apps — heavily enterprise-focused since the AppGyver acquisition. Less relevant for indie builders; included for completeness. April 2026 API policy controversy is ongoing.
  • WeWeb backend (April 2026) — WeWeb launched native Postgres backend (WeWeb Tables) in April 2026. Exportability of this backend layer is not yet fully documented; treat as partial until confirmed.
  • Sovereign Implementer learning curve — "days to first toy app" reflects initial orientation (tooling setup, Git basics, first build cycle). Fluency — the point at which you can scope, build, and maintain a real app end-to-end — develops over months and across multiple projects. Skills are cumulative and transfer across builds in a way platform skills typically don't, but the onramp is not comparable to Glide or Softr.
  • Sovereign Implementer AI-tooling dependency — the deployed app runs independently of any vendor; the builder doesn't. Feature work and bug fixes require Claude Code. The method ships as a Claude Code plugin and isn't ported to other AI tools — if you want to use the doc system with a different AI partner, that's your build to make.
  • Claude Code pricing volatility (mid-2026) — April 2026 saw a brief Pro-tier removal test for a small percentage of new signups (reversed within hours after public reaction). v2.1.100+ has been reported to inflate token consumption by ~40% as of mid-May 2026 (workaround: pin to v2.1.34 or use the npm install rather than the native binary). Verify current pricing and tool behaviour at claude.com before quoting any AI-tooling cost.
  • AI Subscription column — "Bundled" means the AI cost is part of the platform's subscription (single vendor, single bill). "Separate" means the user must hold their own AI vendor account independently — typical for open-source tools (Aider) and the Sovereign Implementer model. "None" means the platform doesn't require AI to function, though some bundle AI assistants at higher tiers.
  • AI-generated code and copyright — the US Copyright Office's current position is that purely AI-generated work is not eligible for copyright; human authorship is required. For builders commercialising a Sovereign Implementer build, this affects what "full IP ownership" actually protects. Not legal advice — consult a lawyer for commercial decisions.
  • IP ownership rows — based on public ToS as of May 2026. Not legal advice. Review current terms before making commercial decisions.
