Two sections. **Processed** — work discussed and agreed, ordered top-to-bottom; /next builds from above the `--- Cleared to run above this line ---` marker. **Unprocessed** — captured, not yet discussed; the next /plan weighs each item. A work line is a `#### ` heading (its description) with a `[slug]` at the end of that line and its rationale in the block beneath. A leading `[audit]` / `[freeform]` / `[user]` tag names how it's executed; no tag means a build. Red flags are ordinary work lines carrying a `Red flag · State: …` marker.
