The no-code method

A Claude Code plugin that keeps your app on track.

What is this?

A structured workflow for non-coders building apps with Claude Code. You describe what your app should do; Claude writes the code. The plugin makes sure Claude follows a rigid process: planning before building, testing before moving on, and keeping written records of every decision.

Without it, Claude drifts. It forgets decisions, builds things nobody asked for, and skips steps. The plugin prevents that with enforced guardrails — locked documents Claude can't edit, file-boundary enforcement it can't bypass, and phase gates it can't skip.

Who is it for?

People who already know what their app should be, but don't write code. You bring the product vision; the method structures how Claude turns it into working software.

Prior Claude Code experience helps but isn't required. Extensive plan-mode use before your first build is recommended.

What does it cost?

Two sessions minimum per feature. One to plan, one to build. Every shipped feature traces to a written rationale. Nothing gets built that nobody decided to build.

That's the trade-off: you move slower, but you never lose track of why something was built, whether it was tested, or what was decided along the way.

Quick start

  1. Install the plugin and run /setup in your project folder.
  2. Describe your app. The plugin walks you through four prompts.
  3. Run /before-build to lock your first batch, then /build to execute it.
  4. Test. Bring results to your next planning session.
