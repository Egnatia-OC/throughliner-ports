# V22 — Planning subagent (drift logic inlined) + Serves-line PreToolUse hook

## Goal

Build the planning subagent with drift checks inlined into its prompt (drift-checker is NOT a separate subagent — subagents can't spawn subagents). Add the third PreToolUse check: block `BACKLOG.md` build batch additions whose `Serves UX.md:` line doesn't point to an existing UX.md entry.

## Inputs

- V18–V20 outputs
- `NO-CODE-METHOD.md` → *During planning* and *How a new feature enters the project*
- `DOC-STRUCTURE.md` → *BACKLOG.md structure* (for the Serves-line format)

## Outputs

- `agents/planning.md` — planning subagent definition (system prompt includes drift-check logic, sort-test-notes logic, `BACKLOG.md` editing protocol, recap rules)
- PreToolUse hook updated with the Serves-line check (parses target build batch on edit, validates `Serves` line, looks up entry in UX.md)
- Commit tagged `v22`

## Success criteria

- Pasting test notes into a Taskflow session triggers the planning subagent (auto-route from V20)
- Drift checks run as part of the planning session and surface mismatches
- `BACKLOG.md` edits land cleanly with discussion-contract honoured (changes discussed in chat, not silent)
- Attempting to add a build batch with a missing or invalid `Serves UX.md:` line is blocked

## Open questions for this session

- How does the planning subagent know its invocation context (test notes vs feature request vs scope question) — does V20's route signal carry this, or does the subagent classify on its own?
- Drift checks: run them every planning session, or skip when nothing has been built since last planning?
- Serves-line check: should it pass-through partial matches (entry name typo) or require exact match?

## Risks / dependencies

- Drift checks inlined may be slow or noisy in chat — may need a verbosity setting
- Planning subagent prompt could grow large with all responsibilities packed in (Opus risk #5: long prompts eat the subagent's context budget)
- Serves-line check is brittle if `BACKLOG.md` format drifts — test against the V17 BACKLOG-TEMPLATE shape
