# V32 — End-to-end Taskflow test

## Goal

Drive a real Taskflow build cycle (planning → before-build → build → after-build) through the full plugin, without manual intervention. Log gaps and bugs surfaced in real use.

## Inputs

- V18–V31 outputs (the complete plugin, after `DOC-STRUCTURE.md` migration and `NO-CODE-METHOD.md` retirement)
- Current Taskflow project state
- Next planned Taskflow batch (or a synthetic one if none is queued)

## Outputs

- Refinement list: every gap, bug, friction point, or missed rule found
- Per-item decision: follow-up session, or defer
- Commit tagged `v32`

## Success criteria

- The cycle runs end-to-end without manual re-routing or workarounds for plugin failures
- All four phases are handled by the right plugin component
- The user can name what the plugin does well and where it falls short

## Open questions

- Which batch — next real one, or a synthetic one chosen for coverage?
- One cycle, or multiple, before declaring V32 done?
- Where does the refinement list live — `planning/sessions/V32-refinement.md`, or straight into V33+ session scopes?

## Risks / dependencies

- Refinement list may spawn more sessions than V32 itself
- Taskflow state must be build-ready: a planning session done, batches queued
- Bugs may require backtracking to V18–V31 to fix
