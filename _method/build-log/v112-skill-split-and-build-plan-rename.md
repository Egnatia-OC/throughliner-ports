# V90 — 2026-05-28 — Skill split: `/sovdeliberate`, `/sovideate`, `/sovplan` narrowing + BACKLOG→BUILD-PLAN rename

**What shipped.** Three planning modes with distinct skills and procedure docs. `/sovplan` narrowed to structural-only (reorder/split/merge batches, drift checks, test read-back). New `/sovdeliberate` for OQ work-through with dispositions logged to build-log. New `/sovideate` for exploring fresh concepts and routing them to OQs, batches, or ideas. Build-snapshot architecture: `/sovbuild` extracts batch to `_method/active-build.md`, unlocking BUILD-PLAN for parallel sessions; `/sovclose` writes batch back as shipped and deletes snapshot. New Ideas section in BUILD-PLAN for lightweight idea capture during any phase. OQ accumulation nudge in SessionStart and `/sovrecap`. Consumer-facing rename from BACKLOG to BUILD-PLAN across all plugin files, templates, guides, and tests. Opener routing updated for three new classifications. Inline git commit steps in each planning-mode procedure doc. 262 tests pass.

**Decisions taken and why.** (1) Build-snapshot over `Status: active` — eliminates the conflation of BUILD-PLAN as both data store and state signal; file existence is unambiguous phase detection. (2) Three skills instead of a monolithic `/sovplan` — users discover each mode through invocation; procedure docs stay focused. (3) BACKLOG→BUILD-PLAN rename — "backlog" contains "log" as substring, causing confusion with "build log"; "build plan" is forward-looking vs "build log" (what was built). (4) Python function/variable names preserved (lowercase "backlog" in `parse_backlog.py`, `resolve_backlog_dir`, etc.) — only consumer-facing strings and constants updated.

**Pivots and surprises.** One pytest failure from a missed fixture directory rename (`fixtures/adopted_proxy/BACKLOG/` — contained files didn't include "BACKLOG" text, so the grep-based identification missed the directory itself). Fixed with a targeted `Get-ChildItem -Filter "BACKLOG" -Directory -Recurse` scan.

**Carried forward.** Nothing.
