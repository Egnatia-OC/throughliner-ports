# V108 — 2026-05-27 — Guided rollback procedure (/sovrevert)

**What shipped.** New `/sovrevert` skill and `revert.md` procedure doc. Walks non-coders through undoing a failed build: identifies changes since last commit, confirms the revert, restores tracked files via `git checkout -- .`, optionally removes untracked files via `git clean -fd`, verifies clean state, and advises committing before future builds. Edge case handled: no prior commit → explain and stop. **Decisions taken and why.** Procedure uses `git checkout -- .` + `git clean -fd` rather than `git stash` or `git reset --hard`. Checkout+clean is the most transparent pair for a non-coder: checkout restores changed files (reversible if they re-edit), clean removes new files (with explicit confirmation). `git reset --hard` would do both silently. Stash would hide changes rather than removing them — confusing for someone who doesn't know git. Untracked file removal is a separate confirmation step because the user might want to keep files the build created.
