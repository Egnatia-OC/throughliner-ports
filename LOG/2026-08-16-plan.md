## Three defects this chat produced or exposed in itself

**A parser defect introduced, diagnosed and cleared within one exchange.** Writing `[adopted-claude-md-describes-retired-structure]` meant quoting the readiness marker's text inside an item's prose. `queue_digest.py` matches that string as a **substring** and takes the first hit inside Processed, so it read that sentence as the readiness line and reported 2 cleared / 5 held against a file with 4 cleared. `reorder_queue.py`, which requires the line to *be* the marker, was right at the same instant. The split is the finding: **the readers that write and enforce use an anchored test; the readers that report use a substring.** `session_start.py` shares the defect, which means the cleared/held counts in every session's opening facts are exposed to it. Filed and cleared as [marker-string-in-prose-moves-the-line].
