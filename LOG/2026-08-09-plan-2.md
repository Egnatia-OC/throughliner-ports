The second: Claude used "it" for three different referents in one passage, could
not be followed, and repaired the problem by stripping pronouns out almost
entirely — which the user reported as condescending. The research they asked for
is at `resources/research/pronoun-use-and-working-memory.md` and **reverses the
premise both parties held**. The repeated-name penalty is a measured result:
repeating a name is read *more slowly* than using a pronoun when the referent is
still in focus, because every backward reference carries an information cost that
has to be earned (Almor's Informational Load Hypothesis, 1999). So the
pronoun-free rewrite was not a neutral clarification — it charged the reader at
every point the pronoun was working, and that also gives the condescension a
mechanism rather than a tone: being handed what you already hold is what
condescension is. The actual defect was never density but referent-switching, and
the two findings partition cleanly, since the penalty disappears once the referent
is no longer the previous sentence's subject. W3C's COGA guidance supplies the one
new idea — impaired working memory may hold only one to three items at once, so
the thing to count is live referents, not pronouns. The drafted rule sits in
`[pronoun-rule-rename-at-the-switch]` for the user to write into the doc
themselves, per the agreement above.
