# 7c9922a — plan.md's two insertion points into Processed now maintain end-preferred placement [lift-step-has-no-placement-rule]

Mixed authorship: the slip and the diagnosis are Claude's; the user caught it, by asking whether some lifted items needed ordering consideration.

**The finding was wider than the item's original framing.** It was filed as a gap in the lift step. Checked at processing: `end-preferred` appeared only in `done-plan.md` and nowhere in `plan.md` at all — so *both* of /plan's insertion points were blind to it, the Step 1 lift and the keep-step. Four items kept into the cleared region in one session landed ahead of the `[user]` lines because Claude chose to, not because any rule required it.

**Why it matters rather than being tidiness.** End-preferred placement is the one reorder [processed-reorder-mostly-unnecessary] deliberately keeps, on the reasoning that batching the stops needing a human is what lets an unattended run stay unattended. A rule kept for that reason and then not applied at the two moments items actually enter the region is a rule in name only. The window is a whole session: the close repairs it, but /next runs before /done, so an item placed at a /plan opening and built the same day is built in the wrong order and the repair arrives after the run it would have helped.

**Written as one cross-reference covering both sites, naming the target document rather than restating the rule.** Two alternatives were rejected and stay rejected: restating the placement rule in `plan.md` creates a second copy that can be edited apart, and a clause at each of the two sites is the same duplication on a smaller scale.

**The folded-in [plan-ground-rules-should-subordinate] was done in the same pass**, as its own text asked. Four parallel imperatives in Ground rules became subordinate units of one opening. Each converted without losing content, so the subordination holds — the instruction was that if any needed forcing, the bullets should be left alone and that said, because forcing a subordination is how such a pass deletes a rule.

An ordering note for whoever reads this next to [processed-reorder-mostly-unnecessary], built in the same run: that item repeals most of the close-out reorder but explicitly keeps end-preferred, which is what this cross-reference resolves to. Had it been dropped, this reference would now point at nothing.
