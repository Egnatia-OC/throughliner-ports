# b931278 — session_start now picks the docset from the running model, falling back to the frozen docset A

This is phase 3 of the two-docset decision: phase 1 recorded the split and froze docset A, phase 2 authored docset B by subtraction, and this wires the automatic selection that makes B reachable at all. Until now B was inert — eleven files no session loaded.

The hook reads the `model` field the SessionStart payload can carry, extracts the family and the first number after it, and routes a major version of 5 or above to docset B. Anchoring on the *first* number is what keeps Haiku 4.5 out of the 5-series bucket: its id ends `-4-5`, and a naive match on "5" would have promoted a 4-series model onto a docset it isn't tuned for. Docset A is the fallback on every uncertain path — an absent `model` field, an id that doesn't parse, any pre-5 family, and an install whose `docs-b/` directory isn't present. That asymmetry is deliberate and was the user's stated reason for freezing A rather than replacing it: guessing wrong toward A costs verbosity, guessing wrong toward B strands a session on a docset its model was never tested against.

The one design problem the build had to solve was reach. Each SKILL.md hardcodes its procedure doc under `docs/`, and a hook cannot rewrite those files, so loading docset B's behaviour rules alone would have left every *procedure* read pointing at docset A — a session governed by one docset and executed by the other, which is worse than either docset used consistently. The fix is an injected directive naming the active docset and instructing the substitution, emitted for docset B only since A needs no redirect. It reaches the unadopted branch too, so a 5-series session doesn't scaffold from docset A and then run every later session on B. The indirection this introduces is real and was captured rather than argued away.

Verification was by driving the hook directly with sample payloads in a temporary project — Opus 5, Fable 5 in its object form, Opus 4.8, Haiku 4.5, and no `model` field at all, plus the unadopted-folder path. All six routed as intended. What this cannot prove is that the desktop app sends a `model` field in the first place; the research was explicit that presence is not guaranteed, and if it is absent here then every session falls back to A and docset B is dead code in this environment. That is queued as its own verification for after the next rezip and restart.
