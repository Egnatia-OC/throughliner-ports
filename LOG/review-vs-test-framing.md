# [HASH] - plan.md + done-build.md + done.md: stop framing a user's eyeball-review of generated output as a pass/fail test

When a batch's only verification was the user reading generated output (a doc, copy, a draft), the method dressed it in test machinery (tick / defer / Deferred tests), mislabelling a natural take-a-look as a checkbox. The fix separates the two: /plan authors an eyeball-review as a plain user review, not under Test; done-build.md frames the close as a plain read-request and holds an unread review as a plain reminder, not a Deferred-tests line; done.md's Deferred tests scope carves the case out. The obligation to look is kept - only the test framing goes.
