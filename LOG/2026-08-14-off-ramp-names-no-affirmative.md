# [HASH] — The /next off-ramp leads with the affirmative — "Say go and I'll start" — instead of naming only the exception

Captured by Alex on 2026-08-13, mid-run, from the message that opened that
session's /next. Her observation in her own words: when the off-ramp says
"otherwise I'll start" there is no explicit guide for what the user should say
next, and "say go and I'll start" or similar would work.

The old specimen — *"Say the word to change scope or reorder — otherwise I'll
start."* — named only the exception in both halves. A user who wants the run to go
ahead was told what happens if they say nothing and given no word for the thing
they actually want to do. It now reads *"Say go and I'll start — or say the word
to change scope or reorder first."*

**A grep run at processing rather than deferred** confirmed this is a single-line
fix and not a pattern: searching the whole docset for off-ramp specimens returned
exactly one hit.

**The one paragraph worth recording is what came out of the doc rather than what
went in.** A why-paragraph was written beneath the new off-ramp and then cut on the
purpose-clause test: deleted, the instruction stayed complete and correctly
applicable, which means it was rationale and belongs here. Only "The affirmative
first, the exception second" survived into the doc, because that is the rule and
not a reason for it. This is the exact defect the audit item later in the same run
went looking for, caught at the keyboard for once rather than found afterwards.

**The evicted rationale, kept here where it belongs.** The affirmative leads
because a user who wants the run to proceed needs a word for the thing they
actually want to do, and "say nothing and it proceeds" is the least reassuring
instruction available to a non-coder at the one deliberate checkpoint before an
unattended run. "Go" is an ordinary word typed in reply rather than a slash
command, so this does not reintroduce the runnable command that other work
deliberately removed from the ends of messages — the tension was noticed and does
not bite.
