# de2f5fc — CLAUDE.md gains the judge-a-design-by-likelihood rule, with its carve-out protecting honest coverage limits

A design is judged by whether it makes the intended outcome more likely, not by whether it guarantees it. A missing guarantee is an objection only where the design depends on that guarantee to work at all. It fires at `/plan`'s keep-step, when weighing whether work is worth doing.

The text was approved in the planning session that wrote it, then blocked by the planning scope-lock, since `CLAUDE.md` is not on the standing writable list. Only the write was deferred; the content was settled.

The carve-out ships with the rule because without it the rule strips the honest limits this project depends on. Statements like "this scan matches credential shapes only" or "this flag reaches only items that name the file" describe what a mechanism covers once built, and exist so the tool never over-claims. The test written into the rule: is the caveat arguing against doing something, or describing what the thing does? The first is the failure; the second is required.

The failure evidence is a single instance and the rule's own text says so, deliberately, so a later reader cannot mistake it for a measured pattern. A planning turn offered "shortening the artifacts may not by itself restore the reading" as a reason to hold work apart, when the work made reading affordable and never depended on the reading happening. A corpus-wide audit for the same pattern was searched for and withdrawn: the other instances checked were refusals on cry-wolf or unapproved-send grounds, which are different arguments and still valid.

This is the costly shape — a freestanding rule, competing with everything rather than amending one thing. Taken deliberately, because no existing rule governs how a design is weighed at the keep-step; the rule gate sitting immediately beneath it governs admitting *rules*, not weighing work.
