# [HASH] — Stated the missing-rule vs sanctioned-override distinction once, where a session actually meets the fork

The item arrived asking for a general override mechanism because four captures circled one. That framing was tested at processing and did not hold, and the reasoning that killed it is what made the remaining work worth doing.

Of the four cases, only one is a departure. A session scrubbed seven files inline during /plan to stop an active exposure: a rule existed, was right, and had to be broken anyway. In the other three there was no rule to break — the skill named docset A and Claude read docset B with nothing written about host routing disagreeing with project config; a /plan procedure ran with no skill around it and nothing detected that; `[user]` verification was driven informally with no routing rule for "I want to verify something." **You cannot depart from something never written.** Calling those departures makes the remedy look like permission when what was missing is authorship.

So the general mechanism would have been built for a population of one, and that one is already specified further in [plan-scope-lock-gap-and-emergency-path] — which shipped in this same run, and whose ask-never-deny gate makes the single genuine override structural rather than exceptional.

What shipped is a short passage, not a mechanism: at a moment the rules don't cover, decide whether this is a missing rule (write it, capture it, don't act) or a right rule that must be broken in this instance (not yours to invent, carries a mandatory record). It sits alongside the discovery-routing rules, which is where a session already decides between acting and capturing.

It earns its place on the active-recurrence test rather than as bookkeeping. Four sessions hit this fork without the distinction available; each improvised, and each improvisation was captured separately as its own problem. Its live job is stopping a session reaching for an override when it should be capturing a missing rule — the more tempting and more damaging of the two errors — so the passage leads with that error rather than with the taxonomy.

The one part of the original framing that survives unchanged: a departure that isn't recorded is indistinguishable from a violation.
