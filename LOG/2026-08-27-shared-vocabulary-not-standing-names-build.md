# 32675a3 — The method's own words are the shared vocabulary; standing aliases are retired

"The ready list" was a standing plain-English name for the queue's cleared region
— a second name for something the method already names in the artifact the user is
looking at. The corpus was growing such names faster than any session could
translate them, and each one costs the user twice: they learn the alias, and they
learn the real thing anyway the moment they open the file.

So the declaration comes out, and in its place: the method's own terms are the
vocabulary spoken with the user — capture, work item, Processed, Unprocessed,
cleared to run, red flag, `[user]` item, walkthrough — each explained once on
first need, and then used. **No plain-English alias is minted for something the
method already names.**

**The translate-away arm is untouched**, and the distinction is the whole of why
this is not a reversal: that arm covers internal mechanics the user's files never
show — step numbers, procedure filenames, tag names — which is a different case
entirely from a word printed in their own queue.

**Dropping the plain-language effort whole was refused**: the user kept it
explicitly, and the jargon failures it exists for are real — one of them processed
the same day as [general-jargon-translate-and-walkthrough-readback], and another
committed by this very session an hour later.

**Grandfathering "the ready list" was refused** as the live instance of the
recursion being dropped.

**Files touched:** `plugin/throughliner/docs/skill-nonspecific-rules.md` (the
Vocabulary section); `plugin/throughliner/docs/plan.md` (the ask specimen, now
"move it into Processed, cleared to run?"); both FAQ templates and their `FAQ/`
copies (three mentions reworded to "cleared to run"). A grep confirms the phrase
appears nowhere in the plugin, FAQ, SPEC, CLAUDE.md or README.

**Routed to Captures:** none.

Retired: "the ready list" — the standing plain-English name for the queue's cleared region.

Rule gate: run — supersession of the ready-list standing-name declaration (evicted in the same move) and amendment of the Vocabulary rule's explained arm into the shared-vocabulary rule; the standing-names idea loses because each admitted name is a second name for a thing the method already names.
