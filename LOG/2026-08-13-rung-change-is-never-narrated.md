# [HASH] — A change of ordering rung is narrated at the pick, not left silent

`plan.md`'s floor-narration passage now says to re-check the rung at every pick
and narrate in one clause only when it has changed, with a pointer at the
checkpoint where the pick happens.

The rules covered a single event — the opening names whichever rung the order came
from — and nothing covered a change once processing was under way. The live
instance: a session opened on rung 4, decay, correctly; the decay-fresh work was
exhausted about ten items later and the picks moved to context adjacency and rung
5 with no narration at all, until the user asked outright what rung was in force.
The honest answer was that the declared one no longer applied. She had been asking
that question in every session, which is what makes it a method gap rather than a
one-off.

A near-miss rule existed and did not bite. The always-loaded file says to narrate
ordering judgment in one short sentence, and stepping down a rung is ordering
judgment — but it is written about placements and reorders, so it does not
obviously reach this, and in practice it did not.

Hanging the check on the pick is the technique the method already uses for the
"what would answer this?" question riding the per-item interview: a standing rule
with no site does not fire, and a rule carried by a step that always runs does.
Narrating on every item is explicitly not proposed — that is the per-item noise
the checkpoint was stripped back to avoid.

The honest limit is written into the text: this reduces the reliance on noticing
and does not remove it. A session that has quietly settled into a different order
can still answer the question wrongly, and nothing here makes the change
detectable from outside.

It belongs in `plan.md`, not the always-loaded file — ordering is /plan's alone,
so a clause there would fail that file's own four-skills admission test.

Rule gate: run — admitted as an amendment to the existing floor-narration rule,
the same obligation reaching a second moment.

FAQ: not needed because the rung vocabulary is internal and what the user sees is
a plain sentence about what is being worked on next.
