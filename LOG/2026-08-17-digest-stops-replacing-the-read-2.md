# [HASH] — the digest and the read are both, and the "instead of" wording is repealed

Three sites said the digest replaces reading QUEUE.md, and all three now say both. `plan.md`'s opening runs the digest for the computed fields and then reads the file for the reasoning; the always-loaded clause blessing a digest as a *stronger* satisfaction of the read-the-whole-file duty is narrowed to the fields a script computes; SPEC's account of the opening is corrected, since it went wrong the moment the other two changed.

The user's reasoning is the argument: the queue is one file because reasoning across items splits badly when they are apart, and a digest of headings restores exactly that split — headings together, reasoning apart. Blockers can be anywhere, and so can the right place to fold something in, so every item bears on any planning session.

The live instance came from the session that raised it. One item carried an instruction that another should wait for it; the instruction was in the prose rather than on the digest line, and the other item was processed first, against it.

What the digest keeps is what reading cannot give: how long an item has been held, where a named blocker sits, which files two items both name, whether a premise cites work that has shipped. So the settlement is both, not either — and the framing matters, because this is not "fix the digest".

The measurement changed the cost argument: 34,287 words across 75 items, about 457 per item against a work-item band top of 229. At band it would be roughly 15,000 words. **So the word bands largely dissolve the reason the digest replaced the read.** A conditional read was offered and refused, because a condition would have to predict which items bear on each other — the thing the read exists to discover.

One thing not claimed: multi-file queues were far worse. This is an occasional feel that something is wrong, and must not be written up as a failure of comparable size.

Rule gate: run — a narrowing of an existing instruction. The eviction is the "instead of reading QUEUE.md" wording, repealed outright.
