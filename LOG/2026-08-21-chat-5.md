  looked at.
- and the same method produced the run's `Runs alone` check and its red-flag check,
  which were clean but were greps rather than reads.

**The common defect is that a grep's misses are invisible.** A file with no match looks
identical to a file that was never searched correctly, and nothing downstream can tell.
This project already has the pattern that fixes it — the required-artifact rules that
turn a silent omission into a visible one, used for the FAQ disposition, the rule-gate
line and the depth field — and none of the three passes above had one. That is worth a
planning session's attention as a single subject rather than three separate repairs, and
it is what the forward advisory points at.
