Reading PLATFORM-CONTRACT.md and the Codex port folder grounded the rework: the Codex port is a full fork governed by its own peer-to-peer PLATFORM-CONTRACT, which the new model supersedes for method changes (reconciliation handed to the Codex side, since that doc can't be edited from here).
