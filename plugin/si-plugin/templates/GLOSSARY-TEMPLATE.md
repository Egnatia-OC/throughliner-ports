# Glossary

Words that have been explained to you, and the names this project has settled
on. Claude keeps this up to date and reads it before using a technical term —
so it doesn't re-explain what you already know, and doesn't assume you know
something it never told you.

Two kinds of entry:

- **Explained terms** — jargon from the wider world. Each one carries the
  explanation roughly as it was last given to you, so it mirrors what you
  might actually remember rather than reading like a textbook.
- **Our names** — words this project chose for its own things, including ones
  you picked yourself. These are simply correct here, whatever the rest of the
  world calls them.

Entries are short on purpose. Ask about any of them at any time and Claude will
explain it again, in whatever way fits the moment — and then update the entry.
