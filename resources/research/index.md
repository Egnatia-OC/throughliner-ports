# Research index

One line per finding, newest first. Each line carries the subject the file settles
and enough of the finding to decide whether to open it, ending in the filename —
the same contract `LOG/index.md` states for itself, and for the same reason: a
session should be able to tell what a file answers without opening it.

**No length cap of any kind.** A line too short to support the open-or-skip
decision fails at any length; a line that reproduces its file fails too.

**Filing a finding writes its index line in the same move.** A file added without
a line is invisible to every later session, which is the blindness this index
exists to end.

**A `Superseded by:` line at the top of a file is noted here too**, so a session
scanning the index sees the correction before it opens the file.

- **Can a model write to a length target without measuring?** — the friend's claim is right and is the field's named root cause: LIFEBench finds models cannot recognise how many words they have generated. But two findings cut the other way and both favour a range here — the documented failure direction under a length instruction is **undershoot**, not overshoot (reproduced exactly by this project's Discord posts landing at ~75% of 2,000 chars every time), and short targets are followed reasonably while the sharp deterioration sits at thousands of words, which is a regime none of this project's shapes occupy. Exact compliance is achievable by three published methods and all three are "generate, measure, regulate", which Alex refused. Extended the same day with the unit question and the range's form: **words, not characters** — character counting runs near a 33% random baseline while word constraints are complied with markedly better, so a range here is stated in words and the Discord character limit works only because it is a ceiling to stay under rather than a target to hit. A **soft band plus a hard ceiling with a named action on breach** is the documented hard-versus-soft constraint pattern, and the action-on-breach is what answers this project's own repealed cap, since advising is not refusing. Also carries the literature's derivation method for the figure — set limits from measured good generations rather than choosing a number. **Corrects its own first reading:** Anthropic's exemplar guidance and this project's local proof of it are about SHAPE, not length, so they do not defeat a numeric range → `llm-length-instruction-following.md`
